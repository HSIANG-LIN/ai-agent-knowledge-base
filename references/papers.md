# AI Agent 核心論文與資源

在深入研究 Agent 技術時，以下是必讀的核心文獻與開源資源。

## 1. 核心論文 (Essential Papers)

### Reasoning & Planning (推理與規劃)
- **ReAct (Reasoning and Acting)**: 結合推理與行動的基礎框架。
- **Reflexion**: 引入自我反思機制，提升 Agent 在複雜任務中的成功率。
- **Toolformer**: 研究如何讓語言模型自主學習使用 API 工具。

### Optimization (優化)
- **DSPy (Declarative Self-improving Language Programs)**: 透過程式化方法優化 Prompt 與模型行為。
- **GEPA (Generalized Evolutionary Prompting Architecture)**: 關於自我演化與評估架構的研究。

## 2. 開源資源 (Open Source Resources)

- **Ollama**: 本地 LLM 部署的最佳選擇。
- **LangChain / LlamaIndex**: Agent 開發的基礎框架。
- **AutoGPT / BabyAGI**: 早期自主 Agent 實驗的代表作。

## 3. 學習路徑建議
1. 先理解 **Prompt Engineering** 的基礎。
2. 學習如何使用 **Function Calling** (工具呼叫)。
3. 研究 **RAG (Retrieval-Augmented Generation)** 以擴展記憶。
4. 探索 **Multi-Agent Collaboration** (多 Agent 協作)。
