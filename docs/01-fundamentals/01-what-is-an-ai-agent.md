# 什麼是 AI Agent？

在人工智慧的演進過程中，我們正從「聊天機器人 (Chatbots)」跨越到「人工智慧代理人 (AI Agents)」的新時代。

## AI Agent 的定義

**AI Agent** 是一種能夠自主感知環境、進行推理規劃，並透過執行行動來達成特定目標的軟體實體。與僅僅根據輸入產生文字的 LLM 不同，Agent 擁有了「行動能力」與「自主決策能力」。

其本質可以理解為：**LLM (大語言模型) 作為「大腦」 + 感知器 (Perception) + 規劃器 (Planning) + 行動器 (Action/Tools)**。

## 核心特性

一個完整的 AI Agent 通常具備以下四項核心特性：

1.  **自主性 (Autonomy)**：能夠在沒有人類持續干預的情況下，根據設定的目標自我驅動，決定下一步該做什麼。
2.  **反應性 (Reactivity)**：能夠感知環境的變化（例如：工具回傳的錯誤、使用者新的指令），並即時調整自身的行為。
3.  **主動性 (Pro-activeness)**：不僅是被動回應，還能為了達成目標而主動採取行動，甚至預判潛在問題。
4.  **社交能力 (Social Ability)**：能夠透過溝通與人類或其他 Agent 協作，以完成複雜的任務。

## 與傳統程式的差異

| 特性 | 傳統程式 (Rule-based) | AI Agent (LLM-based) |
| :--- | :--- | :--- |
| **邏輯基礎** | 基於預定義的 `if-else` 邏輯與固定規則 | 基於 LLM 的推理與動態決策 |
| **靈活性** | 極低，遇到未定義情況會出錯 | 極高，能處理模糊指令與未知場景 |
| **目標達成** | 執行指定的路徑 | 根據目標尋找達成路徑 |
| **環境適應** | 無法適應環境變化 | 能透過觀察環境回饋進行調整 |

## Agent 的生命週期

Agent 的運作通常遵循一個循環過程：

1.  **感知 (Perception)**：接收來自使用者、環境或工具的回饋資訊。
2.  **推理 (Reasoning)**：利用 LLM 進行邏輯分析，理解當前狀態與目標的差距。
3.  **規劃 (Planning)**：將複雜目標拆解為可執行的子任務或步驟。
4.  **執行 (Execution)**：呼叫工具 (Tools) 或 API 來執行具體的行動。
5.  **學習 (Learning/Observation)**：觀察執行結果，並將經驗納入下一次的決策循環中。

## 實作考量

在開發 AI Agent 時，開發者必須面對以下挑戰：

*   **Context Window 管理**：隨著對話與觀察增加，如何有效地管理 Token 使用量並保留關鍵資訊。
*   **Token 預算**：複雜的推理循環會消耗大量 Token，需平衡成本與效能。
*   **錯誤處理 (Error Handling)**：當工具執行失敗或 LLM 產生幻覺時，如何讓 Agent 能夠自我糾正而非陷入死循環。
