# Hermes 生態全景

Hermes 不僅僅是一個 Agent，而是一套完整的開發工具鏈。

## 1. 核心組件
- **rtk-hermes**：提供核心的 Runtime 工具集。
- **mission-control / Dashboard**：可視化的 Agent 狀態監控介面，觀察思考過程與工具呼叫。
- **hermes-plugins / Evey 系列**：一系列預裝的插件，涵蓋搜尋、檔案操作、API 串接。

## 2. 記憶提供者 (Memory Providers)
支援多種後端，包括 SQLite, ChromaDB, Pinecone 等，讓開發者根據需求切換。

## 3. 未來展望
目標是建立一個開放的插件市場，讓任何開發者都能為 Hermes 生態貢獻新的「能力」。
